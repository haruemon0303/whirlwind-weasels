# Audio Assets

このディレクトリには音声ファイルが配置されます。

## プレースホルダ音声について

現在の実装では、Web Audio APIを使用してブラウザ内で音声を動的に生成しています。
これにより、著作権の問題を回避しつつ、基本的なBGMと効果音を提供できます。

### 生成される音声:
- **BGM**: 簡単なトーンの組み合わせでループ再生
- **効果音**:
  - ドアをノック: 低周波のパルス音
  - ライター: 高周波のクリック音
  - 環境音: ノイズベースの音

## カスタム音声ファイルの追加

独自の音声ファイルを使用したい場合:

1. MP3またはOGG形式のファイルを用意
2. 以下のディレクトリに配置:
   - `assets/bgm/` - BGMファイル
   - `assets/se/` - 効果音ファイル
3. `story.json`で対応するファイル名を指定
